### What I've shipped

**[Cybersecurity Educational Game](https://wedad.itch.io/cyber-security-game)** — Unity, C#  
Four-stage game (drag-and-drop, shooter, card-sorting, quiz) built end-to-end for a client. Includes player auth, in-game economy, shop, and completion certificate. Live on itch.io.

**[Cows & Bulls](https://github.com/we-dad/CowsAndBullsGame)** — Unity, C#, PlayFab  
Number-guessing game designed as a working card payment terminal. Player types on a keypad; results print on a paper receipt that feeds out of the machine. Online leaderboard, full Arabic/English localization, native share flow.

**[Space Genie](https://apps.apple.com/sa/app/space-genie/id6450126107)** — Swift, SwiftUI, Firebase, OpenAI  
Published iOS app on the App Store. Interior design marketplace with real-time messaging and an in-app AI assistant. Built with a 3-person team at Apple Developer Academy.

**[Battle Simulator](https://github.com/we-dad/BattleSimulator)** — Unity ECS/DOTS, C#  
Strategy game on a data-oriented architecture. Unit behaviors are modular and swappable without touching combat code — built for performance at high entity counts.

**[Real Estate System](https://github.com/we-dad/real-estate-installment-manager-releases)** — C#, Avalonia, SQLite, Supabase  
Desktop application built solo for a freelance client. Handles property units, tenants, installment schedules, and contract generation. In daily production use.

**[Sambosa Shop](https://github.com/we-dad/SambosaShop)** — Unity URP, C#  
Mobile prototype with procedural paper-folding mesh math, event-driven state machine, and ScriptableObject order data.
